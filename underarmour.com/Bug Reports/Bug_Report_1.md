| Summary:            | Price selection values (25, 150, 200, 500) shift/jitter horizontally when swiping the Gift Card image left or right.                                                                                                                   |
|---------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Priority:           | Low (Visual/UI issue)                                                                                                                                                                                                                  |
| Environment         | Production                                                                                                                                                                                                                             |
| Device:             | Smartphone                                                                                                                                                                                                                             |
| OS:                 | Android 16                                                                                                                                                                                                                             |
| App version:        | 2.73                                                                                                                                                                                                                                   |
| Network:            | Wi-Fi                                                                                                                                                                                                                                  |
|                     |                                                                                                                                                                                                                                        |
| Description         | On the Gift Card product details page, swiping the product image horizontally causes the price selection list to move in the same direction as the swipe. This visual jitter occurs specifically for the values 25, 150, 200, and 500. |
|                     |                                                                                                                                                                                                                                        |
| Steps to Reproduce: |                                                                                                                                                                                                                                        |
| 1.                  | Open the Under Armour app.                                                                                                                                                                                                             |
| 2.                  | Navigate to the Categories - Gift Cards                                                                                                                                                                                                |
| 3.                  | Tap on the "Gift Card" to open it.                                                                                                                                                                                                     |
| 4.                  | In the "Amount" section, select one of the following prices: 25, 150, 200, or 500                                                                                                                                                      |
| 5.                  | Place a finger on the Gift Card image located above the row with price amounts  and swipe it slowly to the left and right.                                                                                                             |
| 6.                  | Observe the movement of the price values below the image.                                                                                                                                                                              |
| Expected Result:    |                                                                                                                                                                                                                                        |
| ·                   | The price selection row and the Gift Card image should not move when swiping the image carousel, regardless of the swipes performed on the Gift Card image above it.                                                                   |
| Actual Result:      |                                                                                                                                                                                                                                        |
| ·                   | The amount prices rows shifts horizontally in the same direction as the swiped Gift Card image, creating a jitter effect.                                                                                                              |
| Repro rate:         |                                                                                                                                                                                                                                        |
| ·                   | 100%                                                                                                                                                                                                                                   |
| Notes:              |                                                                                                                                                                                                                                        |
| ·                   | This appears to be an issue where the price row is unintentionally linked to the image carousel's movement.                                                                                                                            |
