# Manual QA Testing Portfolio Project

## Project
Manual testing of the UnderArmour mobile application for Android.

Application under test:
Under Armour (Mobile App)

## Scope
Testing the core e-commerce and user experience functionality on Android devices:
- Product discovery and Gift Card management.
- Shopping Bag operations and item synchronization.
- "Saved Items" (Wishlist) functionality.
- UI/UX consistency and performance.

- Test Plan

- Checklists
- Bug Reports
- Regression testing
